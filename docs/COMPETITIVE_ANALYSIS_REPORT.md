**編製日期**：2026年2月21日

## 執行摘要

Alice 是一款以 **Telegram 優先、隱私至上** 的 AI 開發審計和成本管理平台，與 Entire Checkpoints（$60M 融資）形成差異化競爭。

**核心洞察**：
- 🎯 **定位差異**：Entire 專注企業級 Git 透明化，Alice 聚焦移動優先 + 隱私優先
- 💡 **市場機會**：遠程工作、跨時區團隊、合規市場（金融/醫療/政府）
- 📱 **獨特優勢**：Telegram 整合、本地化部署、多模態交互
- 💰 **商業模式**：B2B SaaS（企業版）+ 開源社區（免費版）

## 第一部分：Alice 功能清單

### 核心模塊 (10,580 行代碼)

#### 1. **Telegram Bot 集成** ⭐
- **實時互動**：命令驅動 (`/usage`, `/savings`, `/lang` 等)
- **多語言支持**：繁體中文 + 英文 (271+ message keys)
- **速率限制**：防濫用機制
- **按用戶隔離**：每個 Telegram chat ID 獨立 Agent 實例
- **聲音/圖像處理**：多模態輸入支持

#### 2. **智能路由系統** 🧠
- **三層模型選擇**：
  - 用戶手動指令 (`/fast`, `/deep`, `/auto`)
  - AI Triage (OpenAI GPT-4o-mini，~300ms 延遲)
  - 預設模型（Sonnet）
- **成本優化**：40-50% token 成本降低
- **模型範圍**：Haiku (快速) → Sonnet (均衡) → Opus (深度)

#### 3. **性能監測系統** 📈
- **實時指標收集**：
  - Token 消耗追蹤（輸入/輸出）
  - API 呼叫成本計算
  - 工具執行性能記錄
  - 項目路徑級別的成本分解
- **數據可視化**：
  - Token 使用趨勢圖表
  - 模型分佈統計
  - 成本節省報告
  - 性能指標儀表板
- **數據持久化**：SQLite performance_metrics 表

#### 4. **安全和 PII 檢測** 🔒
- **敏感數據識別**：
  - 代碼中的 API Key、密碼、Token 檢測
  - PII（個人可識別信息）檢測
  - 敏感信息分類
- **事件日誌**：security_events 表記錄所有檢測事件
- **管理界面**：
  - Security Events 表（可點選查詳情）
  - PII Detection Records 模態框
  - 脫敏預覽（前 100 字元）
- **不持久化原始數據**：只儲存脫敏摘要

#### 5. **決策日誌和審計** 📋
- **完整決策追蹤**：
  - Agent 思考過程記錄
  - 工具調用日誌
  - 決策原因文檔
- **持久化存儲**：decision_logs 表
- **審查能力**：完整的操作審計日誌

#### 6. **Git 集成** 🔗
- **倉庫狀態追蹤**：
  - 提交歷史監控
  - 分支管理整合
  - 代碼變更追蹤
- **項目路徑追蹤**：每次 API 呼叫記錄 project_path
- **Git 信息提取**：倉庫結構分析

#### 7. **Checkpoint 系統** 💾
- **狀態快照**：保存 Agent 的談話履歷和上下文
- **恢復機制**：從 checkpoint 快速恢復會話
- **上下文管理**：減少長談話的 token 消耗

#### 8. **多代理協調** 🤖
- **特化 Agent**：
  - 代碼審查 Agent
  - 安全審計 Agent
  - 性能分析 Agent
- **任務路由**：根據需求自動分配合適的 Agent
- **結果合併**：多 Agent 結果綜合處理

#### 9. **Web 儀表板** 🖥️
- **React SPA**（前端）+ Go 後端
- **實時 WebSocket 更新**：
  - 決策實時推送
  - 工具執行狀態更新
  - 性能指標即時刷新
- **REST API 支持**：
  - `/api/costs/savings`（成本數據）
  - `/api/model-routing/status`（模型狀態）
  - `/api/language`（語言設置）
  - `/api/security-events`（安全事件）
- **圖表支持**：
  - Source Performance Chart
  - Token Cost Distribution
  - PII Detection Trends
  - Model Usage Distribution

#### 10. **配置靈活性** ⚙️
- **環境變數覆蓋**：支持 12+ 配置項
- **多數據庫支持**：SQLite（本地）
- **可插拔設計**：Tool 系統模塊化
- **日誌配置**：可調節詳細程度

## 第三部分：Alice 差異化策略

### 🎯 定位：「隱私優先的移動開發審計」

#### 核心差異點

##### 1. **移動優先 (Mobile-First)**
- **Telegram 平台優勢**
  - 全球 7.5 億用戶
  - 亞洲尤其普及（中國/台灣之外的替代品）
  - 低網絡流量需求
  - 支持離線操作

- **使用場景**
  - 遠程開發者：隨時隨地監控 AI 成本
  - 出差工程師：飛行中無網絡時也能工作
  - 多時區團隊：跨時區非同步協作
  - 開發工作室：輕量級工具棧

- **競爭優勢**
  - Entire 沒有官方 Telegram bot
  - 用戶無需打開瀏覽器
  - 一鍵命令執行
  - 推送通知實時性好

##### 2. **隱私優先 (Privacy-First)**
- **本地化部署**
  - 代碼永不上傳雲端
  - 敏感數據本地存儲
  - 合規市場 (金融/醫療/政府) 友好
  - 不依賴第三方雲服務

- **PII 檢測**
  - 本地執行敏感信息檢測
  - 脫敏存儲，保護原始數據
  - 審查日誌完整可追蹤
  - 符合 GDPR / 數據隱私法規

- **數據主權**
  - 企業 100% 掌控數據
  - 可離線運行（無網絡依賴）
  - 自管理數據庫（SQLite）
  - 沒有第三方數據共享

- **行銷口號**
  - ✅ **"Never sends code to cloud"**
  - ✅ **"Your data, always in your hands"**
  - ✅ **"Audit AI, without exposing secrets"**

##### 3. **多模態交互 (Multimodal)**
- **語音輸入**
  - Telegram 語音消息支持
  - 開發者可語音提問代碼問題
  - 文字打字效率提升

- **圖像分析**
  - 上傳代碼截圖分析
  - 架構圖識別
  - 錯誤信息截圖理解
  - UI 設計反饋

- **Entire 劣勢**
  - Web 界面不支持語音
  - 圖像分析功能有限
  - 桌面優先設計

##### 4. **智能成本優化 (Smart Cost Management)**
- **AI 路由系統**
  - 自動判斷任務複雜度
  - 簡單任務 → Haiku（7-10 倍便宜）
  - 複雜任務 → Opus（最高質量）
  - 預期節省 40-50% token 成本

- **實時監控**
  - 每個 API 呼叫實時追蹤
  - 項目級別成本分解
  - 模型分佈統計
  - 成本預警機制

- **Entire 劣勢**
  - 主要支持 Claude，模型選擇有限
  - 沒有智能路由
  - 成本控制需要手動干預

##### 5. **亞洲市場策略 (Asia-First)**
- **語言支持**
  - 繁體中文完整支持（271+ keys）
  - 簡體中文規劃中
  - 日文/韓文可擴展

- **市場定位**
  - 台灣：主要市場（政府/金融科技）
  - 香港：金融合規需求
  - 新加坡：多國籍團隊
  - 日本/南韓：技術前瞻性強

- **Entire 劣勢**
  - 全英文界面
  - 不支持中文 Telegram 命令
  - 西方企業導向
