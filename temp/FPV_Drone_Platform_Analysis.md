# DIY FPV 無人機平台分析

**建檔日期**: 2026-03-25
**預算**: $155 USD (標準配置) / $110 USD (最低配置)
**應用場景**: 入門級 FPV (First Person View) 穿越機 / 競技無人機

---

## 📋 I. 系統架構概述

### 核心組件層次

```
┌─────────────────────────────────────────────────────┐
│           飛行控制系統 (Flight Controller)            │
│  ├─ IMU 傳感器 (6-軸/9-軸)                          │
│  ├─ 氣壓計 (可選)                                   │
│  ├─ 磁力計 (可選)                                   │
│  └─ PWM/DShot 輸出 → 4x ESC                         │
├─────────────────────────────────────────────────────┤
│         電源管理 (Power Distribution)                 │
│  ├─ LiPo 電池 (通常 3S-6S)                          │
│  ├─ 分配板 (PDB) / BEC (穩壓模塊)                   │
│  └─ 保險絲 (Protection)                             │
├─────────────────────────────────────────────────────┤
│          無線通信 (Wireless Link)                    │
│  ├─ 接收器 (WiFi/2.4GHz/5.8GHz)                    │
│  ├─ ESP32 (可選，用於遠程監控/數據傳輸)            │
│  └─ 圖傳傳輸 (Video TX)                             │
├─────────────────────────────────────────────────────┤
│            推進系統 (Propulsion)                     │
│  ├─ 4x 無刷電機 (Brushless Motor)                   │
│  ├─ 4x ESC (電子速度控制器)                         │
│  ├─ 4x 螺旋槳 (Propeller) + 反向槳                  │
│  └─ 支架結構 (Frame)                                │
├─────────────────────────────────────────────────────┤
│            感知系統 (Sensing)                       │
│  ├─ 攝像頭 (HD 視頻/FPV)                            │
│  ├─ GPS (可選，定位)                                │
│  ├─ 距離傳感器 (可選)                               │
│  └─ 緊急著陸傳感器 (可選)                           │
├─────────────────────────────────────────────────────┤
│            控制/遙控 (Remote Control)                │
│  ├─ 遙控發射器 (TX)                                 │
│  ├─ 無人機接收器 (RX)                               │
│  └─ 控制協議 (PPM/SBUS/IBUS)                       │
└─────────────────────────────────────────────────────┘
```

## 🔧 II. 關鍵組件深度分析

### 1. 飛行控制器 (Flight Controller - FC)

**職責**:
- 實時IMU數據融合（加速度計、陀螺儀、磁力計）
- PID 控制器 (3軸 roll/pitch/yaw)
- 馬達油門輸出 (PWM 或 DShot 協議)
- 失控保護 (failsafe)

**常見方案**:
- **Betaflight** - 開源韌體，專為 FPV 競技設計
  - PWM/DShot 支援
  - 低延遲 (2-4ms gyro-to-motor)
  - 可調參數豐富

- **iNAV** - 用於自主飛行
  - GPS 集成
  - 航點導航
  - 高度保持

- **ArduPilot** - 企業級穩定
  - 多飛控支援
  - 數據記錄詳細
  - 故障診斷完善

**硬體選項** ($20-40):
- F4 晶片 (STM32F405) - 入門款，性能足夠
- F7/H7 晶片 - 高端，專業級

**集成度考量**:
- 集成 OSD (On-Screen Display) - 實時顯示電壓/電流/飛行數據
- 集成 5V BEC - 為周邊設備供電
- 集成 SD 卡 - 黑匣子記錄

---

### 2. ESP32 微控制器

**用途** (非飛行關鍵):
- 遠程監控 (WiFi 連接)
- 遠程數據傳輸 (飛行數據、視頻幀率、電池狀態)
- 雲端同步
- 行為分析/ML 推理 (如異常檢測)

**集成方案**:
```
FC (飛行控制) ←→ UART/SPI ←→ ESP32 ←→ WiFi/4G
                                    ├→ 遠程儀表板
                                    ├→ 數據記錄
                                    └→ AI 推理
```

**風險**:
- FC 與 ESP32 通信延遲不能影響飛行控制 (must be <10ms)
- 獨立電源供應，避免干擾 FC
- 軟體隔離 (FC 優先級最高)

**成本**: $8-15

---

### 3. IMU 傳感器 (慣性測量單元)

**組成**:
- **加速度計** (3軸) - 檢測速度變化
- **陀螺儀** (3軸) - 檢測旋轉速度
- **磁力計** (3軸，可選) - 指南針功能

**融合算法**:
- Madgwick/Kalman 濾波器
- 快速預測姿態

**常見集成晶片**:
- MPU6050 (6軸) - 最便宜 (~$2)
- BMI088 (6軸) - 工業級
- LSM9DS1 (9軸) - 集成磁力計

**採樣率**: 1kHz - 8kHz (FPV 需要高採樣率確保響應速度)

---

### 4. GPS 模塊 (可選)

**功能**:
- 位置定位 (經度/緯度)
- 高度測量 (GNSS)
- 速度/加速度估算
- 時間同步

**成本**: $15-50

**集成考量**:
- GPS 冷啟動時間: 30-60 秒
- 信號漂移: ±5-10 米
- RTK-GPS: 釐米級精度，但成本 $200+

**應用**:
- Return-to-Home (自動返航)
- 自主航點飛行
- 遠距離監管追蹤

---

### 5. 攝像頭系統

**兩大類型**:

#### A. FPV 實時視頻攝像頭
- 低延遲 (15-50ms)
- 600-1200TVL 解析度
- 寬視角 (150-170°)
- 成本: $10-25

#### B. 高清記錄攝像頭
- 1080p @ 60fps 或 4K
- 延遲可接受 (100-200ms)
- 較窄視角 (90-110°)
- 成本: $20-80

**信號傳輸**:
- 模擬視訊 (AV) - 傳統 FPV，易干擾
- 數位 (USB/HDMI) - 新型無人機，抗干擾
- WiFi 直播 - 低功耗但延遲高

**集成架構**:
```
FPV 攝像頭 → 視訊發射器 (5.8GHz) → 地面站接收
高清攝像頭 → 內存卡 → 事後處理
```

---

### 6. 電調 (ESC - Electronic Speed Controller)

**職責**:
- 將 PWM 信號轉換為 3-相交流電
- 控制無刷電機轉速
- 馬達保護 (過流/過溫)

**關鍵參數**:
- **電流容量**: 20A, 30A, 40A (選擇應≥馬達最大電流 × 1.5)
- **協議**: PWM (傳統) vs DShot (高精度)
- **电压**: 與 LiPo 電池匹配 (3S = 11.1V, 4S = 14.8V)

**PWM vs DShot**:

| 指標 | PWM | DShot |
|------|-----|-------|
| 頻率 | 50Hz | 4-32 kHz |
| 延遲 | 10-20ms | 1-2ms |
| 誤差恢復 | 無 | 有 |
| 成本 | 便宜 ($3-5) | 略貴 ($5-8) |

**推薦**: DShot600 用於 FPV 競技，PWM 用於低成本平台

成本: $4-8 /個 × 4 = $16-32

---

### 7. 無刷電機 (Brushless Motor)

**規格**:
- **KV 值** (轉速常數): KV = RPM/Volt
  - 2200KV → 11V × 2200 = 24,200 RPM (無負載)
  - KV 越高 → 轉速快但扭矩小 (適合小無人機輕螺旋槳)

- **極數**: 12N14P (常見)

- **轉速範圍**: 5,000-35,000 RPM

**選擇原則**:
- 螺旋槳直徑 + 馬達 KV → 穩定懸停推重比 (thrust-to-weight > 2:1)
- 電流消耗 < ESC 額定值

**成本**: $5-15 /個 × 4 = $20-60

---

### 8. 螺旋槳 (Propeller)

**規格**:
- **直徑 × 節距**: 如 5045 (5英寸直徑, 4.5英寸節距)
- **材料**: 塑膠 (易損壞) vs 碳纖 (耐用)
- **旋轉方向**: CW (順時針) vs CCW (逆時針)

**推力計算**:
```
單馬達推力 = f(直徑, 節距, RPM, 電流, 密度)
           ≈ 80-120g /個馬達 (标準配置)
總推力 = 4 × 100g = 400g (無人機重量應 < 150g)
推重比 = 400g / 150g ≈ 2.67 (飛行性能優)
```

**成本**: $1-3 /對 × 4 = $4-12

**損耗**: FPV 飛行常撞牆，螺旋槳快速損耗，建議備用20-30對

---

### 9. LiPo 電池

**規格**:
- **電芯數**: 3S (11.1V) 到 6S (22.2V)
- **容量**: 200-2200 mAh
- **放電率**: 25C-100C (C = 容量)
  - 例: 500mAh @ 50C = 最大電流 500mAh × 50 = 25A

- **重量**: ~1g/100mAh

**選擇**:
- FPV 穿越機: 3S 1300-1500mAh (輕量, 飛行時間 5-8分鐘)
- 長航時無人機: 6S 5000mAh (續航 20+ 分鐘)

**風險**:
- 過充 → 火災
- 過放 → 電池損傷
- 短路 → 爆炸
- 機械損傷 → 內部短路

**安全措施**:
- 使用專業 LiPo 充電器 (平衡充電)
- 防火袋存儲
- 檢查外殼是否膨脹 (puffing)

**成本**: $20-40 (包含充電器和備用電池)

## 🏗️ III. 硬體集成挑戰

### A. 供電設計

```
LiPo (3S 11.1V)
  │
  ├→ FC (5V via BEC)
  │   ├→ IMU 傳感器
  │   ├→ OSD 模塊
  │   └→ 接收器 (5V)
  │
  ├→ 4× ESC + 電機 (直接 11.1V)
  │
  ├→ 攝像頭 (5V via BEC 或專用穩壓)
  │   └→ 視訊發射器 (12V option)
  │
  └→ ESP32 (獨立 5V 穩壓，隔離) ← 關鍵！
```

**問題**:
- 馬達啟動時電流尖峰 (>30A) → 電壓下降
- 多個設備共享同一 BEC → 干擾
- ESP32 獲得噪聲幅度輸入 → 数据傳輸錯誤

**解決方案**:
1. 使用高品質 XT60 連接器 (低壓降)
2. 馬達安裝 4x 100µF 電容 (濾波)
3. FC 和 ESP32 分開電源路徑
4. 使用屏蔽線 (STP cable) 連接 ESP32

---

### B. 通信協議集成

```
遙控發射器 (TX) ─┐
                 ├→ 接收器 (RX) → FC
   GPS           │    ↓
   來源 ─────────┤   UART
                 │    ↑
   ESP32 ────────┴→ UART/SPI → FC
                    互鎖邏輯
```

**協議衝突**:
- SBUS (25Hz) vs IBUS (100Hz)
- PWM (多線) vs UART (單線)
- 電磁干擾 (EMI) → 位元翻轉

**解決**:
- 使用硬體 UART 而非軟體 (避免中斷)
- 訊號完整性檢查 (CRC)
- 優先級: FC 控制 > GPS > ESP32

---

### C. 消耗功率預算

| 組件 | 典型電流 | 飛行時間影響 |
|------|---------|------------|
| 4× 電機 | 15-25A | 大幅消耗 |
| FC + IMU | 0.5A | 輕微 |
| 攝像頭 | 0.3-0.5A | 輕微 |
| GPS | 0.2A | 輕微 |
| ESP32 WiFi | 0.1-0.5A | 輕微 |
| **總計** | **~20A (懸停)** | **100% / 5-8分鐘** |

**結論**: 主要消耗來自電機，其他都是次要。優化螺旋槳效率 > 其他優化

---

### D. 訊號干擾 (EMI/RFI)

**干擾來源**:
- 馬達切換頻率 (8-16kHz)
- 無線發射器 (5.8GHz)
- PWM 邊際 (切換 <1µs)

**影響**:
- IMU 讀取誤差 ± 5-10%
- GPS 信號喪失
- 視頻圖像噪聲

**防護措施**:
1. **空間隔離**: FC 遠離馬達 (≥3cm)
2. **屏蔽**: 將 FC 放入金屬外殼
3. **濾波**: 馬達電源線安裝 π 型濾波器
4. **接地**: 統一地平面 (all GND to battery -)

## 🎯 V. 開發与集成路線圖

### 第一階段: 基礎飛行 (1-2週)

```
1. 組裝機架 + 電機/ESC/槳
   ├─ 焊接電源分配
   ├─ 安裝 FC + 接收器
   └─ 電池連接測試

2. 校準
   ├─ ESC 油門範圍校準
   ├─ 羅盤校準 (若有磁力計)
   └─ 陀螺儀偏差初始化

3. 首次飛行
   ├─ 懸停穩定性測試
   ├─ PID 參數微調
   └─ 故障轉移測試 (信號丟失)
```

### 第二階段: 感知集成 (2-3週)

```
4. GPS 集成
   ├─ UART 連接
   ├─ 信號驗證
   └─ Return-to-Home 測試

5. 攝像頭集成
   ├─ 視訊發射器功率測試
   ├─ 地面站接收器配置
   └─ 視頻延遲量測
```

### 第三階段: 遠程監控 (3-4週)

```
6. ESP32 集成
   ├─ UART 通信建立
   ├─ 數據幀格式定義
   ├─ WiFi 傳輸測試
   └─ 遠程儀表板開發

7. 故障診斷
   ├─ 黑匣子記錄 (log)
   ├─ 異常檢測 (AI)
   └─ 遠程告警系統
```

## 🔗 IX. 與 GPU 平台的集成機會

### 應用場景

```
無人機群 (100架)
  ├→ 每架飛行數據 (1KB/秒)
  ├→ 匯聚到中央協調器
  ├→ 發送至 GPU 租賃平台
  └→ 執行任務:
      ├─ 實時路徑優化 (MILP 求解) → GPU 加速
      ├─ 環境 3D 重建 (SfM) → GPU 加速
      ├─ 異常檢測 (ML) → GPU 推理
      └─ 結果回傳至無人機群
```

### 成本效益
- **GPU 需求**: ~1-2 個 A100 (用於 100 架編隊)
- **計算費用**: $0.50-1.00 /小時 (按需計費)
- **應用**: 搜救、農業、測繪
